# 🌦️ Station météo connectée — ESP32

## 1. Présentation du projet

Projet de station météo connectée conçue pour acquérir des mesures environnementales, récupérer des informations météo en ligne et afficher les données sur une matrice LED. Il met en pratique l’intégration de capteurs, la programmation embarquée et la communication réseau dans un système IoT.

## 2. Objectifs

- Mesurer la température, l’humidité et la luminosité.
- Récupérer des données météo en ligne via une API.
- Transmettre les données par Wi-Fi.
- Afficher les informations sur une matrice LED.
- Tester le fonctionnement des différents éléments intégrés.

## 3. Matériel et outils utilisés

| Élément | Utilisation |
|---|---|
| ESP32 | Microcontrôleur principal |
| C | Programmation embarquée |
| AHT20 | Mesure de la température et de l’humidité |
| BH1750 | Mesure de la luminosité |
| Wi-Fi et API Web | Communication et récupération de données |
| Matrice LED HUB75 | Affichage des informations |

## 4. Étapes de réalisation

1. Étudier le fonctionnement de l’ESP32 et des capteurs.
2. Câbler et configurer les composants.
3. Programmer l’acquisition et le traitement des mesures.
4. Mettre en place la connexion Wi-Fi et les requêtes vers l’API météo.
5. Intégrer l’affichage des informations sur la matrice LED.
6. Tester les échanges de données et corriger les erreurs détectées.

## 5. Compétences mobilisées

- Programmation embarquée en C
- Intégration et lecture de capteurs
- Acquisition et traitement de données
- Communication Wi-Fi et utilisation d’une API
- Tests fonctionnels et débogage

## 6. Résultats et validation

Le projet vise à réunir les mesures locales et les informations météo en ligne dans un système d’affichage embarqué. Les résultats peuvent être documentés avec des exemples de mesures, des tests de communication et des photos du système fonctionnel.
