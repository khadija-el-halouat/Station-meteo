# 🌦️ Station météo connectée — ESP32

## Présentation

Projet de station météo embarquée conçue pour acquérir des mesures environnementales, récupérer des informations météo en ligne et afficher les données sur une matrice LED.

L’objectif est de mettre en pratique l’intégration de capteurs, la programmation en C sur microcontrôleur et la communication réseau dans un système IoT.

## Fonctionnalités

- Acquisition de la température et de l’humidité avec le capteur AHT20.
- Mesure de la luminosité avec le capteur BH1750.
- Connexion au réseau Wi-Fi.
- Récupération de données externes via une API météo.
- Affichage des informations sur une matrice LED HUB75.

## Technologies et matériel

| Élément | Utilisation |
|---|---|
| ESP32 | Microcontrôleur principal |
| C | Programmation embarquée |
| AHT20 | Température et humidité |
| BH1750 | Luminosité |
| Wi-Fi et API Web | Récupération et échange de données |
| Matrice LED HUB75 | Affichage |

## Démarche de réalisation

1. Étudier le fonctionnement de l’ESP32 et des capteurs.
2. Câbler et configurer les composants.
3. Programmer l’acquisition et le traitement des mesures.
4. Mettre en place la connexion Wi-Fi et les requêtes vers l’API.
5. Intégrer l’affichage sur la matrice LED.
6. Tester les échanges de données et corriger les erreurs.

## Compétences mobilisées

- Programmation embarquée en C
- Intégration de capteurs et communication entre composants
- Acquisition et traitement de données
- Communication Wi-Fi et utilisation d’une API
- Tests fonctionnels et débogage

## Résultat

Le projet vise à réunir les mesures locales et les informations météo en ligne dans une interface d’affichage embarquée.
