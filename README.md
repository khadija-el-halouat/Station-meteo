# Station météo connectée

# Robot aspirateur (Roomba)

Objectif:
L’objectif de ce projet était de concevoir une station météo embarquée capable de mesurer différentes données environnementales en temps réel, puis de les traiter et les afficher localement tout en exploitant des informations récupérées sur Internet. Le projet visait également à découvrir l’intégration de capteurs, la communication réseau et l’utilisation d’un microcontrôleur dans une application IoT complète.

Technologies utilisées:

. ESP32
. Langage C
. Capteur BH1750
. Capteur AHT20
. Wi-Fi
. API Web
. Matrice LED HUB75

Étapes du projet:

1. Étude du fonctionnement des capteurs et du microcontrôleur ESP32
2. Connexion et configuration des capteurs environnementaux
3. Développement du programme d'acquisition des données en C
4. Mise en place de la communication Wi-Fi
5. Récupération de données externes via une API météo
6. Affichage des informations sur une matrice LED
7. Tests, correction des erreurs et optimisation du fonctionnement

Compétences développées:

- Programmation embarquée en C
- Acquisition et traitement de données
- Communication entre composants électroniques
- Utilisation d’API Web
- Débogage et validation système

Résultats:

. Système capable d'afficher des données environnementales en temps réel
. Intégration réussie de données locales et externes
. Compréhension approfondie des systèmes IoT
